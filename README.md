This repository contains my early practice files for learning backend web development. It focuses on the very basics of Node.js and how to set up a simple web server using Express.js. 

## What is Inside?

This project is split into two main practice folders to keep topics clear and separate:

### 1. Import_Export
This folder contains simple JavaScript files (`script.js`, `script1.js`, `script2.js`) to practice how Node.js handles modules.
* **Key Lesson:** Learning how to share code and logic between different files.
* **Important Rule:** I learned that only one `module.exports` exists in a single file.

### 2. Express JS
This folder contains a basic server setup using the Express framework.
* **Key Lesson:** How to start a server, manage packages with `npm`, and send web pages to the user.
* **Files Included:** Contains `script.js` for server logic, a `views` folder for web pages, and `package.json` to track installed tools.
